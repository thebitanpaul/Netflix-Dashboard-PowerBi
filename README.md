# NetflixDashboard

<img src="https://res.cloudinary.com/b0tb1mho/image/upload/v1784642029/f5rg8yihnulranqxm2pc.webp"/>

An interactive **Power BI dashboard** built to analyze and visualize Netflix's content library through rich business intelligence visualizations. The dashboard provides insights into movies, TV shows, genres, countries, ratings, release trends, and other key metrics using an intuitive and modern reporting experience.

## Features

* Interactive dashboard with cross-filtering
* Content distribution analysis
* Movies vs TV Shows comparison
* Genre-wise insights
* Country-wise content visualization
* Yearly content addition trends
* Rating and certification analysis
* Responsive report layout
* Business Intelligence focused visual storytelling
